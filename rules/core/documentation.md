- [DOC-001 SHOULD] Update README or docs in the same change when behavior, setup, configuration or commands change.
- [DOC-002 SHOULD] Document every environment variable with purpose and default in .env.example or docs.
- [DOC-003 SHOULD] Write comments that explain why, not what; delete comments that are no longer true.
- [DOC-004 SHOULD] Keep a CHANGELOG or release notes for anything other repos consume.
